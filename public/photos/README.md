# Photos Folder

Put your personal photos in this folder (`public/photos/`).

Currently configured photos in `src/config/surpriseConfig.js`:
- `photo-01.jpg` through `photo-12.jpg`
- `photo-13-final.jpg` (displayed as the final featured photo)

To add, replace, or reorder photos:
1. Copy your image files (`.jpg`, `.jpeg`, `.png`, `.webp`) into `public/photos/`.
2. Update the `PHOTOS` array in `src/config/surpriseConfig.js`.
3. Every path should start with `/photos/your-filename.jpg`.
