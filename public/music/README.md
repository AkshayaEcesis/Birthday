# Background Music Folder

To use your own romantic song instead of the built-in ambient piano melody:

1. Place your MP3 file in this folder and name it `romantic-melody.mp3` (`public/music/romantic-melody.mp3`).
2. Or place any audio file here and update `MUSIC_CONFIG.customTrackUrl` in `src/config/surpriseConfig.js`.

Note: Music never autoplays before the recipient interacts with the page. It starts softly after she clicks "Open this little surprise" (or taps the floating music button).
